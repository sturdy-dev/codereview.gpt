# Функция "Объяснить с помощью AI"

## Описание

Новая функция позволяет выделить любой текст на веб-странице, кликнуть правой кнопкой мыши и выбрать пункт контекстного меню **"Объяснить с помощью AI"**. После этого откроется плавающее окно, где можно дописать дополнительный вопрос и получить объяснение от нейросети.

## Возможности

✨ **Контекстное меню** - выделите текст → правый клик → "Объяснить с помощью AI"  
✨ **Дополнительный вопрос** - можно добавить свой вопрос к выделенному тексту  
✨ **Плавающее окно** - не блокирует работу с сайтом  
✨ **Drag & Drop** - можно перемещать окно  
✨ **Изменение размера** - можно изменять размер окна  
✨ **Streaming ответов** - ответ появляется в реальном времени  
✨ **Markdown форматирование** - поддержка кода, списков, заголовков

## Как использовать

### Шаг 1: Выделите текст
Выделите любой текст на веб-странице, который хотите объяснить.

### Шаг 2: Откройте контекстное меню
Кликните правой кнопкой мыши по выделенному тексту.

### Шаг 3: Выберите "Объяснить с помощью AI"
В контекстном меню выберите пункт **"Объяснить с помощью AI"**.

### Шаг 4: (Необязательно) Добавьте свой вопрос
В открывшемся окне вы можете добавить дополнительный вопрос, например:
- "Что делает эта функция?"
- "Объясни простыми словами"
- "Какие есть недостатки в этом коде?"
- "Как это можно улучшить?"

### Шаг 5: Нажмите "Объяснить"
Нажмите кнопку **"Объяснить"** или используйте сочетание клавиш **Ctrl+Enter**.

### Шаг 6: Получите ответ
Нейросеть проанализирует выделенный текст и ваш вопрос, и предоставит объяснение в реальном времени.

## Управление окном

### Перемещение
Кликните и удерживайте заголовок окна, чтобы перемещать его по экрану.

### Изменение размера
Потяните за правый нижний угол окна, чтобы изменить его размер.

### Кнопки управления
- **Центрировать** (⊕) - размещает окно в центре экрана
- **Свернуть** (−) - сворачивает окно в заголовок
- **Закрыть** (×) - закрывает окно

## Технические детали

### Архитектура

```
Пользователь выделяет текст
    ↓
Правый клик → "Объяснить с помощью AI"
    ↓
background.js получает событие contextMenus.onClicked
    ↓
Отправляет сообщение в content.js с выделенным текстом
    ↓
content.js создает/показывает FloatingExplainWindow
    ↓
Пользователь (опционально) добавляет вопрос
    ↓
Нажимает "Объяснить"
    ↓
Запрос отправляется в API через streaming
    ↓
Ответ отображается в реальном времени
```

### Измененные файлы

1. **public/manifest.json**
   - Добавлено разрешение `"contextMenus"`

2. **src/background.js**
   - Создание контекстного меню при установке расширения
   - Обработчик клика по контекстному меню
   - Отправка выделенного текста в content script

3. **src/content.js**
   - Новый класс `FloatingExplainWindow`
   - Обработка сообщения `explainText`
   - Интеграция со streaming API

4. **src/styles.css**
   - Стили для окна объяснений
   - Стили для формы ввода вопроса
   - Стили для отображения результата

## Конфигурация

Функция использует те же настройки API, что и основное расширение:

- **API Key** - задается в настройках расширения
- **API Base URL** - OpenAI, Ollama, LM Studio, и др.
- **Model** - используемая модель (gpt-3.5-turbo, qwen3-coder:30b, и т.д.)
- **AI Explain Prompt** - настраиваемый промпт для объяснений (NEW!)

### Настройка промпта для объяснений

Вы можете настроить, как AI будет объяснять текст:

1. Кликните правой кнопкой по иконке расширения
2. Выберите **"Параметры"** или **"Options"**
3. Прокрутите вниз до раздела **"AI Explain Prompt"**
4. Отредактируйте промпт по своему вкусу
5. Нажмите **"Сохранить"**

#### Доступные переменные в промпте:

- `{text}` - выделенный пользователем текст
- `{question}` - дополнительный вопрос пользователя (если был задан)

#### Пример кастомного промпта:

```
Ты опытный программист и преподаватель.

Проанализируй следующий фрагмент:
{text}

{question}

Твой ответ должен включать:
1. Краткое описание (1-2 предложения)
2. Подробное объяснение как это работает
3. Потенциальные проблемы или улучшения
4. Примеры использования (если уместно)

Используй простой язык, подходящий для разработчика среднего уровня.
```

#### Дефолтный промпт:

Если не задан кастомный промпт, используется следующий:

```
Ты полезный AI ассистент. Твоя задача - объяснить выделенный текст понятно и на русском языке.

Выделенный текст:
{text}

{question}

Требования к ответу:
- Объясняй понятно и структурировано
- Используй примеры, где это уместно
- Если это код, объясни что он делает и как работает
- Если есть потенциальные проблемы или улучшения, укажи на них
- Отвечай на русском языке
- Будь кратким, но информативным
```

## Отладка

### Content Script
1. Откройте веб-страницу
2. Нажмите F12 (DevTools)
3. Вкладка Console
4. Ищите логи с префиксом `[CS]`

### Background Script
1. Откройте `chrome://extensions`
2. Найдите расширение
3. Кликните **"service worker"**
4. Ищите логи с префиксом `[BG]`

## Безопасность

- API ключи хранятся в `chrome.storage.sync` (зашифровано)
- Background script изолирован от веб-страницы
- Content script не имеет прямого доступа к API ключам
- Все запросы к API проходят через background script

## FAQ

**В: Можно ли использовать без API ключа?**  
О: Да, если настроена локальная модель (Ollama, LM Studio).

**В: Сколько текста можно выделить?**  
О: Зависит от модели. Обычно 2000-4000 слов для GPT-3.5, больше для GPT-4.

**В: Можно ли изменить язык ответа?**  
О: Да, укажите в дополнительном вопросе: "Ответь на английском" или другом языке.

**В: Работает ли на GitHub/GitLab?**  
О: Да, работает на любых веб-страницах.

**В: Можно ли использовать вместе с окном Code Review?**  
О: Да, оба окна работают независимо друг от друга.
